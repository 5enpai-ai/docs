## 2.4 Frequency scale

The labels come from the brief. The thresholds are mine so the labels stay consistent, and you can change them. Frequency is always counted over watched originals only.

| Label | Share of watched originals |
| --- | --- |
| Nearly every video | ≥ 90 % |
| Majority | > 50 % and < 90 % |
| Recurring | 25–50 % |
| Occasional | 2 videos, < 25 % |
| Isolated | 1 video |

No scores or rankings are used.
