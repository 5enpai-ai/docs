### How to fill in a beat

- Write one beat per slot, and copy a slot if you need more.
- **Canon references touched:** name the canon items the beat uses, such as a character, ability, prop or location from audit §A. Also list any open-thread IDs (T1–T20, section 2) the beat touches, so the continuity gate can check them.
- **Required source/reference art:** list the existing panels, sheets, or designs the art must match. Mark it **NEEDED** if no reference exists yet.
- Leave a field blank if you haven't decided it. Nothing will be filled in for you.

### Continuity gate (runs after the beats are supplied, before any credits)

For each beat, the gate checks:

1. Every canon reference matches audit §A. Position A is unchanged.
2. Nothing is added that the beat doesn't state: no dialogue, events, or explanations.
3. Each touched open thread (T-ID) is handled exactly as the beat states. Threads the beat doesn't touch stay UNRESOLVED.
4. Appearance and props carry over from the 14d starting point, or the beat states the change.
5. Every **NEEDED** reference is supplied or approved before generation.
6. Each beat is tagged CANON (supplied by you) or ADAPTATION (vertical staging only).
