# Higgsfield unlimited week: Wan 3.0 prompt pack

ÜNDR (the world) + Hoshoku (Bunni 🐰 and Renard 🦊). The week runs **Oct 14–20**.

## The core workflow (do this every time)

1. **Lock the look on an unlimited image model first.** Use Nano Banana Pro or Seedream 4.5. Generate the character or scene as a still. Rerun it until it looks right. Stills are free and quick, and video tries are what you're short on.
2. **Animate the still in Wan 3.0.** Use the **+** button and add the still as the start frame (image-to-video). Starting from your still keeps Bunni and Renard looking the same in every clip. Text-only video will make them look different each time.
3. **Always keep a generation running.** Each time a slot opens, start the next one from the list below. Running nothing wastes the week.
4. **Save good results right away.** Sort them into folders: `site/`, `vtuber/`, `social/`.

Paste your VTuber model's reference art into every character still you make. Without it, Bunni and Renard won't match your actual model.

## Prompt tips for Wan

- Describe **one camera move + one action**. Wan does poorly when you stack several actions.
- Add "seamless loop", "slow motion", or "locked-off camera" when you want a clip for a background.
- Put style words last: "anime cel-shaded", "35mm film grain", "high contrast".
- If hands or faces break, shorten the clip and simplify the action. Don't keep rerolling the same prompt.
